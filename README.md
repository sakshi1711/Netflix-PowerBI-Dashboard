 Netflix Content Analysis Dashboard

 Project Overview

The Netflix Content Analysis Dashboard is a data analytics project designed to explore and analyze Netflix's content library. The project focuses on understanding content distribution, identifying trends, and generating meaningful insights through interactive data visualization.
 Project Objectives

- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify content trends based on release years.
- Explore content distribution across different countries.
- Analyze popular genres and categories.
- Understand the growth and expansion of Netflix's content library.
- Present meaningful insights through visual dashboards.

 Tools & Technologies Used

- Microsoft Excel – Data cleaning and preparation.
- Power Query – Data transformation.
- Charts & Visualizations – Representing analytical findings.
- Dashboard Design – Presenting insights in an interactive and understandable format.

 Data Cleaning & Preparation

The dataset was prepared by performing the following tasks:

- Identifying and handling missing values.
- Removing duplicate records wherever required.
- Formatting and organizing data.
- Transforming columns for better analysis.
- Preparing data for visualization.

 Key Analysis Performed

- Movies vs. TV Shows distribution.
- Content added over the years.
- Country-wise content distribution.
- Genre-wise analysis.
- Rating-wise content distribution.
- Content release trends.
